What policy should I use each hour?

The planner compares the rest of the day from one shared pump state, follows the selected policy for the next hour, then replans. Uses historical sunlight from this dataset; this is a replay recommendation, not a future forecast.

Uncertainty experiments

Challenge all four policies on the selected replay day. Each sampled scenario shares the same sunlight and groundwater inputs across policies. Runs start at rest for this isolated day.

Feasibility requires the full daily target and zero low-water-risk hours. Win frequencies describe sampled assumptions; they are not confidence levels or safety certificates.
